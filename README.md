# AI-Based OTT Content Screening System

An AI-based web application that analyzes uploaded OTT video content and identifies potentially risky or sensitive content. The system is designed to support content screening by automatically analyzing video data and generating a risk assessment.

## 🚀 Features

- Upload video clips for screening
- AI-based content analysis
- Risk detection and classification
- Risk score generation
- Simple web-based interface using Streamlit
- Stores application data using SQLite
- Displays screening results in an easy-to-understand format

## 🛠️ Technologies Used

- **Python**
- **Streamlit**
- **Artificial Intelligence / Machine Learning**
- **OpenCV**
- **Transformers**
- **SQLite**
- **Pandas**
- **NumPy**

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/harini020306/AI-Based-OTT-Content-Screening-System.git
```

### 2. Open the project folder

```bash
cd AI-Based-OTT-Content-Screening-System
```

### 3. Install the required packages

```bash
pip install -r requirements.txt
```

## ▶️ Run the Application

Start the Streamlit application using:

```bash
streamlit run app.py
```

The application will open in your browser.
